# Заявки с сайта → Google Таблица

> **Если заявки идут в таблицу с тестом эмпата** — используется
> [Скрипт-таблицы-целиком.gs](Скрипт-таблицы-целиком.gs): один скрипт на всё,
> с листами «Тест эмпата», «Предзапись», «Предзапись с сайта» и «Заявки
> на продукт». Вставляется в Apps Script этой таблицы целиком, вместо
> прежнего содержимого. Отдельный Code.gs ниже тогда не нужен.

Сайт статический, своего сервера у него нет. Приёмником работает веб-приложение
Apps Script внутри таблицы: оно принимает заявку и дописывает строку.
Тот же скрипт принимает результаты теста эмпата — поэтому все контакты
лежат в одной таблице, разными листами.

## Где что лежит

| Лист | Что падает |
|---|---|
| «Тест эмпата» | сырьё теста |
| «Предзапись» | заявки из приложения теста |
| «Предзапись с сайта» | заявки с сайта предзаписи |
| «Заявки на продукт» | заявки с сайта оплаты |

Код — [Скрипт-таблицы-целиком.gs](Скрипт-таблицы-целиком.gs). Вставляется
в Apps Script таблицы целиком, вместо прежнего содержимого.

## Если меняете скрипт потом

`Развернуть` → `Управление развёртываниями` → карандаш → `Версия: Новая`.
Адрес `/exec` при этом не меняется. Если создать *новое* развёртывание вместо
редактирования старого, адрес станет другим и заявки перестанут доходить —
он вшит в site.js.

## Что попадает в таблицу

Время, имя, телефон, Telegram, готовность (предзапись) или тариф (оплата),
галки согласий, время акцепта, редакции документов, адрес страницы
и User-Agent.

## Две вещи, которые стоит знать

**IP-адреса не будет.** Apps Script не отдаёт скрипту ни IP, ни заголовки
запроса. В ТЗ IP указан как обязательное поле лога согласия — получить его
можно только на настоящем сервере или через прослойку вроде Cloudflare
Worker. User-Agent приходит со стороны браузера, то есть теоретически может
быть подделан клиентом.

**Google — иностранный обработчик.** Имя, телефон и Telegram — персональные
данные, а Google Таблицы лежат за границей. По 152-ФЗ это трансграничная
передача: нужно уведомление в Роскомнадзор до первой заявки и договор
поручения обработки. В `_ЧТО-ОСТАЛОСЬ.md` уведомление уже стоит в блокерах —
там оно про доступ Виолы к базе, здесь добавляется ещё одно основание.
Российский приёмник этого пункта не требует.
